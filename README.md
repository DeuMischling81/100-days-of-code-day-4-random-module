# 100-days-of-code-day-4-random-module
Day 4 covered importing random modules to make random selections from the lists that we are either creating or using to achieve a random outcome.

We also learned to to modify lists and and extend them using the .append() function. 

We were tasked with creating a list of names to draw from, to decide who pays for lunch (reference lunch-roulette.py). 

Using the collective knowledge of everything we've learned up to day 4, we were tasked with creating a Rock, Paper, Scissors game, that pulls from a list and compares the users selection to the computers selection, and based on the rules, determines the winner (reference rock-paper-scissors-game-project.py).
